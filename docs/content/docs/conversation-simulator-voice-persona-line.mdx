`LineSettings` controls **the connection the simulated caller is on**. Set it as `line` on a [`Persona`](/docs/conversation-simulator-voice-personas).

Most voice agents are reached over the phone, and phone lines are worse than a TTS voice makes them sound. `LineSettings` puts the caller's speech through the kind of connection your real callers are on, so your agent's speech recognition has to work through it.

Under each setting is a recording of the same caller saying the same sentence with it applied. Pick a value to hear it. `dropouts` and `garbled` use a longer sentence, with one, three and six faults in it at `"rare"`, `"normal"` and `"frequent"`. Recorded with `OpenAITTSModel(model="gpt-4o-mini-tts")`. Start with the caller with nothing set, then switch between a few settings to compare:

## Create Line Settings

```python
from deepeval.dataset import Persona, LineSettings

persona = Persona(
    characteristics="You are calling from your car.",
    line=LineSettings(quality="phone", dropouts="rare", static=0.2),
)
```

There are **SIX** optional parameters when creating a `LineSettings`:

- [Optional] `quality`: either `"wideband"`, `"phone"`, `"mobile"` or `"speakerphone"`. Defaulted to `"wideband"`.
  - `"wideband"` is the clean voice as the TTS model made it.
  - `"phone"` is a landline: band-limited to 300–3400 Hz and μ-law encoded.
  - `"mobile"` is a weak mobile connection: a narrower band, encoded more coarsely.
  - `"speakerphone"` is a caller talking from across a room: quieter, with the room echoing, on a phone line.

  Echo is sent while the agent is talking, so it needs a connector that supports [interruptions](/docs/conversation-simulator-voice-interruptions). It stops while the caller is saying something and picks up again after, and it is never recorded as a turn.

The line works on streamed and whole utterances alike and costs nothing. Faults fall in the same places every time you run the same persona, so a failure you find is one you can reproduce.

## Using The Phone Filter On Its Own

To apply the phone filter outside a simulation, wrap any TTS model in `PhoneLineTTS`:

```python
from deepeval.models.tts import OpenAITTSModel
from deepeval.voice.phone_line import PhoneLineTTS

tts_model = PhoneLineTTS(OpenAITTSModel())
```
