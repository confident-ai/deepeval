The `ZeroWidth` attack method interleaves **zero-width Unicode characters** (U+200B/C/D) between the characters of the baseline attack, breaking up keyword substrings for naive filters while the visible text stays legible to the model.

## Usage

```python title="main.py"
from deepeval.red_team import red_team
from deepeval.red_team.vulnerabilities import Bias
from deepeval.red_team.attacks.single_turn import ZeroWidth
from somewhere import your_callback

zerowidth = ZeroWidth(weight=2)

red_team(
    attacks=[zerowidth], 
    vulnerabilities=[Bias()], 
    model_callback=your_callback
)
```

There is **ONE** optional parameter when creating a `ZeroWidth` attack:

- [Optional] `weight`: an integer that determines this attack method's selection probability, proportional to the total weight sum of all `attacks` during red teaming. Defaulted to `1`.

:::note
The `weight` is only applicable for the `red_team` function and does not when used as a standalone.
:::

### As a standalone

You can enhance any attack using the `enhance` method:

```python
from deepeval.red_team.attacks.single_turn import ZeroWidth
from somewhere import your_callback

base_attack = "Your initial harmful prompt targeting a specific vulnerability"
zerowidth = ZeroWidth()

enhanced_attack = zerowidth.enhance(base_attack)
print(enhanced_attack)
```
