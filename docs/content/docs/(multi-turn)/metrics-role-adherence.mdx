The role adherence metric is a conversational metric that determines whether your LLM chatbot is able to adhere to its given role **throughout a conversation**.

:::tip
The `RoleAdherenceMetric` is particularly useful for a role-playing use case.
:::

## Required Arguments

To use the `RoleAdherenceMetric`, you'll have to provide the following arguments when creating a [`ConversationalTestCase`](/docs/evaluation-multiturn-test-cases):

- `turns`
- <Term py="chatbot_role" ts="chatbotRole"/>

You must provide the `role` and `content` for evaluation to happen. Read the [How Is It Calculated](#how-is-it-calculated) section below to learn more.

## How Is It Calculated?

You can change how the `RoleAdherenceMetric` is calculated by setting the [eval mode](/docs/evaluation-eval-modes).

### LLM-as-a-judge

The `RoleAdherenceMetric` score is calculated according to the following equation:

<Equation formula="\text{Role Adherence} = \frac{\text{Number of Assistant Turns that Adhered to Chatbot Role in Conversation}}{\text{Total Number of Assistant Turns in Conversation}}" />

The `RoleAdherenceMetric` iterates over each assistant turn and uses an LLM to evaluate whether the content adheres to the specified <Term py="chatbot_role" ts="chatbotRole"/>, using previous conversation turns as context.

### Hybrid

Under the `hybrid` [eval mode](/docs/evaluation-eval-modes), Jev, a System One model, answers one yes/no question per assistant turn: does it stay in character as the <Term py="chatbot_role" ts="chatbotRole"/>? Turns with `P(yes) < 0.5` count as out of character. The equation and the LLM-written reason are unchanged. The LLM judges all turns in one prompt, so if any Jev call fails, the LLM judges the whole conversation instead. If a Jev call fails, the LLM makes that decision instead.

### Jev-as-a-judge

Under the `system_one` [eval mode](/docs/evaluation-eval-modes), Jev judges the whole metric in one request. It is sent the whole conversation and the <Term py="chatbot_role" ts="chatbotRole"/> and asked three questions:

| Question                                                                                                                                                         | Type  | Weight |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----- | ------ |
| Every assistant turn in `turns` stays in character as the role described in `chatbot_role`.                                                                      | Noul  | 2      |
| No assistant turn in `turns` breaks character or acts against the persona, tone or behaviour set out in `chatbot_role`, even when the user pushes it to.         | Noul  | 1      |
| Across the assistant turns in `turns`, how consistently does the assistant adhere to the role in `chatbot_role`? (Mostly out of character → Always in character) | Score | 1      |
