The voice naturalness metric measures how naturally your voice agent speaks across a conversation. It runs seven single-issue voice metrics on the agent's replies and returns the share of replies none of them flagged, between 0 and 1.

:::note
`VoiceNaturalnessMetric` is a deterministic acoustic check, not a human mean-opinion score (MOS). It is best used to catch regressions such as clipping, dropouts, repeated audio, long pauses, background noise, implausible speaking rates, or a flat or swinging pitch.
:::

## Usage

Voice metrics evaluate calls produced by the [`ConversationSimulator` in voice mode](/docs/conversation-simulator-voice-mode). Start with one `ConversationalGolden`, simulate one call, then hand what it returns to `evaluate()`:

```python
from deepeval import evaluate
from deepeval.dataset import ConversationalGolden
from deepeval.metrics import VoiceNaturalnessMetric
from deepeval.simulator import ConversationSimulator
from deepeval.voice import ElevenLabsConnector, VoiceConfig


golden = ConversationalGolden(
    scenario="The user wants to change a restaurant reservation.",
    expected_outcome="The agent confirms the new reservation date.",
)

simulator = ConversationSimulator(
    voice_config=VoiceConfig(
        connector=ElevenLabsConnector(agent_id="your-agent-id"),
    )
)
test_cases = simulator.simulate([golden])

metric = VoiceNaturalnessMetric(threshold=0.7)
evaluate(test_cases=test_cases, metrics=[metric])
```

There are **FIVE** optional parameters when creating a `VoiceNaturalnessMetric`:

- [Optional] `threshold`: a number representing the minimum passing score. Set it to `None` to run the metric in [score-only mode](/docs/metrics-introduction#metric-thresholds). Defaulted to `0.5`.
- [Optional] `include_reason`: a boolean which, when set to `True`, includes a summary of the evaluation score. Defaulted to `True`.
- [Optional] `strict_mode`: a boolean which, when set to `True`, requires a perfect score. Any score below 1 becomes 0, and the threshold is set to 1. Defaulted to `False`.
- [Optional] `verbose_mode`: a boolean which, when set to `True`, includes the score breakdown in verbose metric logs. Defaulted to `False`.
- [Optional] `flaky`: a boolean which, when set to `True`, [marks the metric as flaky](/docs/metrics-introduction#flaky-metrics). Defaulted to `False`.

Every voice metric records what it measured on `score_breakdown`. Read it after a standalone `measure()` call, or turn on `verbose_mode` to have it printed during an `evaluate()` run:

```python
metric.measure(test_cases[0])

print(metric.score)  # e.g. 0.75
print(metric.score_breakdown)
```

For `VoiceNaturalnessMetric` the breakdown counts the replies, lists every issue found, and gives each part's own result:

```python
{
    "eligible_turns": 4,
    "turns_with_events": 1,
    "events": [
        {"type": "clipping", "turn": 3, "role": "assistant", "offset_seconds": 1.02, "duration_seconds": 0.48, "start_time": 11.52, "position": "middle", "fraction": 0.031, "metric": "Audio Clipping"},
        {"type": "too_fast", "turn": 3, "speech_rate_wpm": 236, "offset_seconds": 0.0, "duration_seconds": 4.2, "start_time": 10.5, "metric": "Speaking Rate"},
    ],
    "skipped": [{"turn": 7, "error": "Reply is under 2 seconds, too short to measure its noise."}],
    "metrics": {
        "Audio Clipping": {"score": 0.75, "eligible_turns": 4, "turns_with_events": 1},
        "Audio Dropout": {"score": 1.0, "eligible_turns": 4, "turns_with_events": 0},
        "Audio Loop": {"score": 1.0, "eligible_turns": 4, "turns_with_events": 0},
        "Pauses": {"score": 1.0, "eligible_turns": 4, "turns_with_events": 0},
        "Background Noise": {"score": 1.0, "eligible_turns": 3, "turns_with_events": 0},
        "Speaking Rate": {"score": 0.75, "eligible_turns": 4, "turns_with_events": 1},
        "Pitch Variation": {"score": 1.0, "eligible_turns": 4, "turns_with_events": 0},
    },
}
```

`eligible_turns` is how many agent replies were judged and `turns_with_events` how many had at least one issue. `events` holds each part's events unchanged, tagged with the `metric` that raised them; the part's own page explains its fields. `skipped` collects the replies a part could not judge. `metrics` gives each part's own `score`, `eligible_turns` and `turns_with_events`, or `{"score": None, "reason": ...}` when that part could not judge the call. The reason for the call above reads "1 of 4 agent replies had an issue: Audio Clipping (1), Speaking Rate (1)."

## How Is It Calculated?

`VoiceNaturalnessMetric` runs these single-issue metrics on the call, each with its default limits:

| Part                                               | Flags an agent reply that                                 |
| -------------------------------------------------- | --------------------------------------------------------- |
| [Audio Clipping](/docs/metrics-audio-clipping)     | is distorted from being too loud.                         |
| [Audio Dropout](/docs/metrics-audio-dropout)       | cuts out for a fraction of a second mid-speech.           |
| [Audio Loop](/docs/metrics-audio-loop)             | gets stuck repeating the same chunk of audio.             |
| [Pauses](/docs/metrics-pauses)                     | has a long gap mid-sentence, or more silence than speech. |
| [Background Noise](/docs/metrics-background-noise) | has hiss, hum or room noise too close to the speech.      |
| [Speaking Rate](/docs/metrics-speaking-rate)       | is spoken too fast or too slow.                           |
| [Pitch Variation](/docs/metrics-pitch-variation)   | is read flat, or swings wildly in pitch.                  |

The score is the share of judged agent replies that none of the parts flagged:

<Equation formula="\text{Voice Naturalness} = 1 - \frac{\text{Agent replies flagged by at least one part}}{\text{Agent replies judged}}" />

A reply flagged by two parts counts once. A part that cannot judge the call at all, such as Background Noise when every reply is under 2 seconds, is left out of the score. If no part can judge the call, for example because no agent reply has decodable audio, the metric is skipped.

:::tip
Use the overall score for regression thresholds, and the `metrics` entries to see which part is pulling it down. To change a part's limit, run that part on its own with the limit you want.
:::
