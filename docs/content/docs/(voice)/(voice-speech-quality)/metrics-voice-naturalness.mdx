The voice naturalness metric checks whether your voice agent **sounds like a person talking**. It runs seven single-issue voice metrics on the agent's replies and returns the share of replies none of them flagged, between 0 and 1.

## Required Arguments

To use the `VoiceNaturalnessMetric`, you'll have to provide a [`ConversationalTestCase`](/docs/evaluation-multiturn-test-cases) with:

- `audio` on the agent's turns

The `content` on the agent's turns is optional. Speaking Rate only uses it to skip replies that spell something out.

Read the [How Is It Calculated](#how-is-it-calculated) section below to learn how each is used.

## Usage

The `VoiceNaturalnessMetric()` can be used for [end-to-end](/docs/evaluation-end-to-end-multi-turn) evaluation of voice calls, such as ones produced by the [`ConversationSimulator` in voice mode](/docs/conversation-simulator-voice-mode):

```python
from deepeval import evaluate
from deepeval.dataset import ConversationalGolden
from deepeval.metrics import VoiceNaturalnessMetric
from deepeval.simulator import ConversationSimulator
from deepeval.voice import ElevenLabsConnector, VoiceConfig


golden = ConversationalGolden(
    scenario="The user wants to change a restaurant reservation.",
    expected_outcome="The agent confirms the new reservation date.",
)

simulator = ConversationSimulator(
    voice_config=VoiceConfig(
        connector=ElevenLabsConnector(agent_id="your-agent-id"),
    )
)
test_cases = simulator.simulate([golden])

metric = VoiceNaturalnessMetric(threshold=0.7)
evaluate(test_cases=test_cases, metrics=[metric])
```

The `VoiceNaturalnessMetric` takes only the [common voice metric parameters](/docs/metrics-voice-introduction#using-voice-metrics). Its parts always run with their default limits. To change a limit, run that part on its own.

### As a standalone

You can also run the `VoiceNaturalnessMetric` on a single test case as a standalone, one-off execution:

```python
metric.measure(test_cases[0])

print(metric.score, metric.reason)
print(metric.score_breakdown)
```

See [Events](#events) for what `score_breakdown` contains.

| Field | What it means |
| --- | --- |
| `metric` | The part that raised the event. That part's page explains the event's other fields |
| `skipped` | Replies a part couldn't judge, one entry per part, so a reply can appear more than once |
| `metrics` | Each part's own score and counts. A part that couldn't judge any reply shows a `score` of `None` and a `reason` instead |

Every event also has the [fields all voice events share](/docs/metrics-voice-introduction#events), such as `mark` and `description`. There's no top-level `timing_source`, as only per-turn audio is read.

`eligible_turns` is how many agent replies at least one part judged and `turns_with_events` how many at least one part flagged. The score is the share that weren't flagged.

## How Is It Calculated?

The `VoiceNaturalnessMetric` score is calculated according to the following equation:

<Equation formula="\text{Voice Naturalness} = \frac{\text{Number of Agent Replies No Part Flagged}}{\text{Total Number of Agent Replies Judged}}" />

The metric reads each agent turn's own clip, or replies cut from stereo full call audio when no turn has audio. The caller's turns are ignored.

### Parts

Each agent turn with audio is one reply. These seven parts judge it, each with its default limits:

| Part | Flags a reply that | Judges a reply with |
| --- | --- | --- |
| [Audio Clipping](/docs/metrics-audio-clipping) | is distorted from being too loud | audio that decodes |
| [Audio Dropout](/docs/metrics-audio-dropout) | cuts out for a moment mid-speech | audio that decodes |
| [Audio Loop](/docs/metrics-audio-loop) | repeats the same chunk of audio | audio that decodes |
| [Pauses](/docs/metrics-pauses) | pauses over 4 seconds, or is over 50% silence | 2 seconds of speech or more |
| [Background Noise](/docs/metrics-background-noise) | has speech under 18 dB above the noise | a clip of 2 seconds or more that isn't silent |
| [Speaking Rate](/docs/metrics-speaking-rate) | is under 3.5 or over 10 syllables a second | 2 seconds of speaking time or more, and text that doesn't spell something out |
| [Pitch Variation](/docs/metrics-pitch-variation) | moves its pitch under 1 semitone over a clip of 4 seconds or more | 1 second of voiced speech or more |

### Combining parts

- A reply counts if at least one part judged it.
- A reply is flagged if at least one part flagged it. Two parts flagging the same reply count once.
- A part that can't judge any reply, such as Background Noise when every reply is under 2 seconds, is left out.

If no part can judge any reply, the metric is [skipped](/docs/metrics-voice-introduction#when-a-metric-is-skipped).
