The pauses metric checks whether your voice agent **pauses naturally while it speaks**: no long gap in the middle of a sentence, and not more silence than speech. It returns the share of agent replies with natural pauses, between 0 and 1.

## Usage

Voice metrics evaluate calls produced by the [`ConversationSimulator` in voice mode](/docs/conversation-simulator-voice-mode). Start with one `ConversationalGolden`, simulate one call, then hand what it returns to `evaluate()`:

```python
from deepeval import evaluate
from deepeval.dataset import ConversationalGolden
from deepeval.metrics import PausesMetric
from deepeval.simulator import ConversationSimulator
from deepeval.voice import ElevenLabsConnector, VoiceConfig


golden = ConversationalGolden(
    scenario="The user asks the agent to look up an order by its number.",
    expected_outcome="The agent reads back the order status.",
)

simulator = ConversationSimulator(
    voice_config=VoiceConfig(
        connector=ElevenLabsConnector(agent_id="your-agent-id"),
    )
)
test_cases = simulator.simulate([golden])

metric = PausesMetric(threshold=0.8, max_pause_ms=2000, max_pause_percent=50)
evaluate(test_cases=test_cases, metrics=[metric])
```

There are **SEVEN** optional parameters when creating a `PausesMetric`:

- [Optional] `threshold`: a number representing the minimum passing score. Set it to `None` to run the metric in [score-only mode](/docs/metrics-introduction#metric-thresholds). Defaulted to `0.5`.
- [Optional] `include_reason`: a boolean which, when set to `True`, includes a summary of the evaluation score. Defaulted to `True`.
- [Optional] `strict_mode`: a boolean which, when set to `True`, requires a perfect score. Any score below 1 becomes 0, and the threshold is set to 1. Defaulted to `False`.
- [Optional] `verbose_mode`: a boolean which, when set to `True`, includes the score breakdown in verbose metric logs. Defaulted to `False`.
- [Optional] `max_pause_ms`: an integer for the longest pause, in milliseconds, allowed inside a reply. Defaulted to `2000`.
- [Optional] `max_pause_percent`: an integer for the largest share of a reply, in percent, that may be pauses. Defaulted to `50`.
- [Optional] `flaky`: a boolean which, when set to `True`, [marks the metric as flaky](/docs/metrics-introduction#flaky-metrics). Defaulted to `False`.

`score_breakdown` lists the replies where the issue was found:

```python
metric.measure(test_cases[0])

print(metric.score)  # e.g. 0.75
print(metric.score_breakdown)
```

```python
{
    "eligible_turns": 4,
    "turns_with_events": 1,
    "events": [{"type": "long_pause", "turn": 3, "longest_pause_ms": 3120}],
    "skipped": [{"turn": 5, "error": "Reply has under 2 seconds of speech."}],
}
```

`turn` is the turn's zero-based position in the conversation. An event's `type` is `long_pause`, with the reply's `longest_pause_ms`, or `too_much_silence`, with its `pause_fraction`. A reply with both counts once, as a long pause. Agent replies whose audio could not be decoded, or that have under two seconds of speech, are listed under `skipped`.

## How Is It Calculated?

`PausesMetric` checks every agent reply with at least two seconds of speech, and scores the share of them with natural pauses:

<Equation formula="\text{Pauses} = \frac{\text{Agent replies without a long pause or too much silence}}{\text{Agent replies with two or more seconds of speech}}" />

Only the time from the reply's first spoken sound to its last is checked. Silence before the agent starts talking is response time, not a pause. A pause is a stretch of at least 200 ms with no speech in it; shorter gaps are part of saying words (Campione & Véronis, 2002). On a reply with background noise, anything within 6 dB of the noise counts as pause, so a pause is still found when the line is never truly silent.

Long pauses in spontaneous speech cluster around 1.5 seconds (Campione & Véronis, 2002), and conversation tends to treat about one second of silence as the standard maximum (Jefferson, 1989). The default of **2 seconds** sits above both. The default of **50%** flags a reply with more silence than speech.
