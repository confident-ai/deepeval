The background noise metric checks whether your voice agent's speech has **a constant hiss, hum or room noise behind it**. It compares how loud the agent's speech is with the noise underneath it, and returns the share of agent replies where the speech stands well clear of the noise, between 0 and 1.

## Usage

Voice metrics evaluate calls produced by the [`ConversationSimulator` in voice mode](/docs/conversation-simulator-voice-mode). Start with one `ConversationalGolden`, simulate one call, then hand what it returns to `evaluate()`:

```python
from deepeval import evaluate
from deepeval.dataset import ConversationalGolden
from deepeval.metrics import BackgroundNoiseMetric
from deepeval.simulator import ConversationSimulator
from deepeval.voice import ElevenLabsConnector, VoiceConfig


golden = ConversationalGolden(
    scenario="The user asks the agent to look up an order by its number.",
    expected_outcome="The agent reads back the order status.",
)

simulator = ConversationSimulator(
    voice_config=VoiceConfig(
        connector=ElevenLabsConnector(agent_id="your-agent-id"),
    )
)
test_cases = simulator.simulate([golden])

metric = BackgroundNoiseMetric(threshold=0.8, min_snr_db=20)
evaluate(test_cases=test_cases, metrics=[metric])
```

There are **SIX** optional parameters when creating a `BackgroundNoiseMetric`:

- [Optional] `threshold`: a number representing the minimum passing score. Set it to `None` to run the metric in [score-only mode](/docs/metrics-introduction#metric-thresholds). Defaulted to `0.5`.
- [Optional] `include_reason`: a boolean which, when set to `True`, includes a summary of the evaluation score. Defaulted to `True`.
- [Optional] `strict_mode`: a boolean which, when set to `True`, requires a perfect score. Any score below 1 becomes 0, and the threshold is set to 1. Defaulted to `False`.
- [Optional] `verbose_mode`: a boolean which, when set to `True`, includes the score breakdown in verbose metric logs. Defaulted to `False`.
- [Optional] `min_snr_db`: an integer for the lowest signal-to-noise ratio, in dB, that a reply may have before its noise counts as an issue. Defaulted to `20`.
- [Optional] `flaky`: a boolean which, when set to `True`, [marks the metric as flaky](/docs/metrics-introduction#flaky-metrics). Defaulted to `False`.

`score_breakdown` lists the replies where the issue was found:

```python
metric.measure(test_cases[0])

print(metric.score)  # e.g. 0.75
print(metric.score_breakdown)
```

```python
{
    "eligible_turns": 4,
    "turns_with_events": 1,
    "events": [{"type": "background_noise", "turn": 3, "estimated_snr_db": 14.2}],
    "skipped": [],
}
```

`turn` is the turn's zero-based position in the conversation, and `estimated_snr_db` is the reply's estimated signal-to-noise ratio. Agent replies whose audio could not be decoded are listed under `skipped` with the error.

## How Is It Calculated?

`BackgroundNoiseMetric` checks every agent reply that has audio and scores the share of them without the issue:

<Equation formula="\text{Background Noise} = \frac{\text{Agent replies at or above min\_snr\_db}}{\text{Agent replies with decodable audio}}" />

Each reply is cut into 20 ms frames. The **speech level** is the 90th percentile of the frames loud enough to be speech, and the **noise level** is the 10th percentile of all frames, which lands in the pauses between words. The signal-to-noise ratio is the gap between the two in dB. A reply with a ratio below `min_snr_db` has background noise.

The default of **20 dB** is where noise behind speech becomes clearly audible. Clean synthetic speech usually measures above 60 dB, and noise at −45 dBFS behind normal speech measures about 30 dB.

If no agent reply has decodable audio, the metric is skipped.
