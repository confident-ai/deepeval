The audio dropout metric checks whether your voice agent's audio **cuts out mid-speech**: a fraction of a second goes missing, as in "Your appoint… is confirmed". It returns the share of agent replies with no dropout, between 0 and 1.

<AudioSample name="audio-dropout" />

## Required Arguments

To use the `AudioDropoutMetric`, you'll have to provide a [`ConversationalTestCase`](/docs/evaluation-multiturn-test-cases) with `audio` on the agent's turns.

The metric only reads [turn audio](/docs/metrics-voice-introduction#call-audio-vs-turn-audio). Call audio on the test case is ignored. An `Audio.start_time` on each clip is optional, and only used to place events on the call's clock.

## Usage

The `AudioDropoutMetric()` can be used for [end-to-end](/docs/evaluation-end-to-end-multi-turn) evaluation of voice calls, such as ones produced by the [`ConversationSimulator` in voice mode](/docs/conversation-simulator-voice-mode):

```python
from deepeval import evaluate
from deepeval.dataset import ConversationalGolden
from deepeval.metrics import AudioDropoutMetric
from deepeval.simulator import ConversationSimulator
from deepeval.voice import ElevenLabsConnector, VoiceConfig


golden = ConversationalGolden(
    scenario="The user asks the agent to look up an order by its number.",
    expected_outcome="The agent reads back the order status.",
)

simulator = ConversationSimulator(
    voice_config=VoiceConfig(
        connector=ElevenLabsConnector(agent_id="your-agent-id"),
    )
)
test_cases = simulator.simulate([golden])

metric = AudioDropoutMetric(threshold=0.8)
evaluate(test_cases=test_cases, metrics=[metric])
```

The `AudioDropoutMetric` has no optional parameters of its own. It takes only the [common voice metric parameters](/docs/metrics-voice-introduction#using-voice-metrics).

### As a standalone

You can also run the `AudioDropoutMetric` on a single test case as a standalone, one-off execution:

```python
metric.measure(test_cases[0])

print(metric.score, metric.reason)
print(metric.score_breakdown)
```

See [Events](#events) for what `score_breakdown` contains.

## Events

Each dropout shows up in `score_breakdown` as its own event. Here is what the [example call](#example-call) returns:

```python
{
    "eligible_turns": 4,
    "turns_with_events": 1,
    "events": [
        {
            "type": "audio_dropout",
            "turn": 5,
            "offset_seconds": 1.1,
            "duration_seconds": 0.08,
            "start_time": 13.75,
            "mark": "range",
            "timing_source": "turn_timestamps",
            "description": "Audio dropped out for 80 ms",
        }
    ],
    "skipped": [],
}
```

Dropout events carry only the [fields all voice events share](/docs/metrics-voice-introduction#events). `offset_seconds` and `duration_seconds` cover the gap inside the turn's clip. Clips that can't be decoded are listed under `skipped`.

`eligible_turns` is how many agent replies were counted and `turns_with_events` how many had a dropout. A reply with several dropouts counts once. The score is the share that had none.

## How Is It Calculated?

The `AudioDropoutMetric` score is calculated according to the following equation:

<Equation formula="\text{Audio Dropout} = \frac{\text{Number of Agent Replies Without a Dropout}}{\text{Total Number of Agent Replies}}" />

Each agent clip that decodes is one reply. The caller's clips are never checked.

### Dropout criteria

A dropout is a short gap where the sound falls away in the middle of speech. A pause between words keeps the room's background noise, or fades in and out. A dropout doesn't.

<VoiceDiagram
  duration={6}
  lanes={[

  ]}

    { at: 1.72, lane: 0, tone: "ok", label: "pause" },
    { at: 3.45, lane: 0, tone: "bad", label: "dropout" },
  ]}
/>

How a gap is judged depends on the clip's pauses:

| Clip | A gap is a dropout when |
| --- | --- |
| Pauses have background noise | Its quietest moment falls to 10% or less of the clip's typical pause noise |
| Pauses are near-silent, as with clean TTS | It is near-zero for at least 20 ms, and the sound on both sides stops and starts sharply |

In both cases:

| Check | Rule |
| --- | --- |
| Length | 200 ms or less |
| Place | Sound on both sides, not at the clip's start or end |
| Sharp edges (near-silent clips only) | The 5 ms at each edge are at least 25% of the level of the 60 ms beside them |

If there's nothing to count, the metric is [skipped](/docs/metrics-voice-introduction#when-a-metric-is-skipped).
