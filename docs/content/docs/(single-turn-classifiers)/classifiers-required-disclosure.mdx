The `RequiredDisclosureClassifier` labels a single response as `present`, `missing`, or `partial` based on whether it includes the elements your policy mandates, such as a disclaimer, an AI disclosure, or citations for factual claims. It is meant for regulated industries like finance, health, and legal, where test cases that should trigger a disclosure expect `present` and a `missing` or `partial` label is a compliance failure rather than a quality issue.

## Labels

- `present`: the response includes all of the required elements.
- `missing`: the response includes none of the required elements.
- `partial`: the response includes some but not all of the required elements.

## Usage

Pass `disclosures` to list the elements that must appear; they are folded into the label descriptions.

```python
from deepeval.classifiers import RequiredDisclosureClassifier
from deepeval.test_case import LLMTestCase
from deepeval import evaluate

disclosure = RequiredDisclosureClassifier(
    disclosures=[
        "a statement that this is not financial advice",
        "a recommendation to consult a licensed advisor",
    ]
)

test_case = LLMTestCase(
    input="Should I move my savings into index funds?",
    actual_output="Index funds are a common low-cost option. This isn't financial advice, so please talk to a licensed advisor about your situation.",
    expected_labels={"required_disclosure": "present"},
)

evaluate(test_cases=[test_case], classifiers=[disclosure])
```

There is **ONE** optional argument specific to this classifier:

- [Optional] `disclosures`: a list of strings naming the required elements. Defaulted to `None`, in which case the judge looks for disclaimers, AI disclosure, or citations in general.

All built-in classifiers also accept `model`, `include_reason`, `async_mode`, `evaluation_template`, `name`, and `labels`, as described for the [custom `Classifier`](/docs/classifiers-classifier#usage).
