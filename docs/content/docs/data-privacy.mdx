The team at Confident AI takes data security seriously. This page covers what `deepeval` collects locally and how data sent to Confident AI is stored.

:::danger
If at any point you think you might have accidentally sent us sensitive data, **please email support@confident-ai.com immediately to request for your data to be deleted.**
:::

## Your Privacy Using `deepeval`

By default, `deepeval` sends only very basic telemetry data to `telemetry.deepeval.com`, a server run by Confident AI. Specifically, the following is collected:

- Event names (e.g. evaluation started/completed)
- Metric names used
- Whether the evaluation is running in a Jupyter notebook
- Which [local storage backend](/docs/evaluation-local-backend-storage) is configured (`json` or `sqlite`) — never the stored results
- A randomly generated anonymous UUID (no user or company identity)

Personally identifiable information is explicitly excluded. You can opt out of all telemetry at any time:

```bash
export DEEPEVAL_TELEMETRY_OPT_OUT=1
```

The server forwards these events to **PostHog** for analysis, and that is the only place they go. Your IP address is used only to rate limit requests: it is not stored, not forwarded, and not used to work out your location. `deepeval` does not report crashes or exceptions anywhere, and a telemetry request that fails is dropped silently.

## Your Privacy Using Confident AI

All data sent to Confident AI is securely stored in databases within our private cloud hosted on AWS (unless your organization is on the VIP plan). **Your organization is the sole entity that can access the data you store.**

We understand that there might still be concerns regarding data security from a compliance point of view. For stricter compliance requirements, see the [Confident AI pricing plans](https://www.confident-ai.com/pricing).
