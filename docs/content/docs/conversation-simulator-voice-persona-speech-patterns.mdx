`SpeechPatternSettings` gives the simulated caller **the habits real people have on the phone**. Set it as `speech_patterns` on a [`Persona`](/docs/conversation-simulator-voice-personas).

Each pattern is `"rare"`, `"normal"` or `"frequent"`, and is off when left as `None`.

Under each setting is a recording of the same caller saying the same sentence with it applied. Pick a value to hear it. The wording patterns are heard on the caller's reply after the agent offers some appointment times, written by the simulator model with the pattern off, at `"normal"` and at `"frequent"`. Recorded with `OpenAITTSModel(model="gpt-4o-mini-tts")`. This is the caller with nothing set:

## Create Speech Pattern Settings

```python
from deepeval.dataset import Persona, SpeechPatternSettings

persona = Persona(
    characteristics="You are calling from a busy cafe and keep losing your train of thought.",
    speech_patterns=SpeechPatternSettings(
        fillers="frequent",
        mid_sentence_pauses="normal",
        self_corrects="rare",
    ),
)
```

There are **EIGHT** optional parameters when creating a `SpeechPatternSettings`, in two groups.

## Timing Patterns

These change how the caller's audio is timed and mixed, and are voice-only. They test whether your agent knows when it is being spoken to and when the caller has finished.

- [Optional] `mid_sentence_pauses`: how often the caller stops for a second or two in the middle of a sentence and then carries on. An agent that answers during the pause has cut them off.

```python
persona = Persona(
    characteristics="You grew up in Miami and mix English and Spanish without noticing.",
    languages=["English", "Spanish"],
    speech_patterns=SpeechPatternSettings(switches_language="normal"),
    multilingual_stt=True,
)
```

:::note
A pattern that is `"frequent"` shows up in roughly six utterances out of ten, `"normal"` in about a third, and `"rare"` in about one in seven. Which utterances is decided from the persona, so the same persona makes the same call every time.
:::
