The `ConversationInstructionCompletenessClassifier` labels a whole conversation as `complete`, `partial`, or `dropped` based on whether every part of a compound task spread across several turns was eventually addressed, only some parts were, or parts raised earlier were forgotten by the end. It is meant for assistants handling multi-step tasks over a conversation, where the expected label is `complete` and a `dropped` label pinpoints requests that fell out of the assistant's working memory.

## Labels

- `complete`: every request the user made during the conversation is addressed by the end.
- `partial`: some of the user's requests are addressed by the end and others are not.
- `dropped`: requests the user made earlier in the conversation are forgotten and never addressed.

## Usage

```python
from deepeval.classifiers import ConversationInstructionCompletenessClassifier
from deepeval.test_case import ConversationalTestCase, Turn
from deepeval import evaluate

completeness = ConversationInstructionCompletenessClassifier()

test_case = ConversationalTestCase(
    turns=[
        Turn(role="user", content="Book me a table for two on Friday, and remind me to bring the gift card."),
        Turn(role="assistant", content="Which restaurant and what time on Friday?"),
        Turn(role="user", content="Luigi's at 7pm."),
        Turn(role="assistant", content="Booked: Luigi's, Friday 7pm, for two. I've also set a reminder for the gift card."),
    ],
    expected_labels={"conversation_instruction_completeness": "complete"},
)

evaluate(test_cases=[test_case], classifiers=[completeness])
```

All built-in classifiers accept the same optional arguments as a [custom `Classifier`](/docs/classifiers-classifier#usage): `model`, `include_reason`, `async_mode`, and `evaluation_template`. You can also override `name` or pass your own `labels`.
