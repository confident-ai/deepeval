`deepeval` supports using [TypeSafe AI](https://typesafe.ai)'s Jev, a [System One model](https://docs.typesafe.ai/concepts/system-one), as the judge for its metrics<Only id="python"> and classifiers</Only> under the `hybrid` and `system_one` [eval modes](/docs/evaluation-eval-modes), and for [`JevEval`](/docs/metrics-jev-eval). To get started, you'll need to install the TypeSafe AI SDK and set up your API key.

### Setting Up Your API Key

Install the TypeSafe AI SDK, then provide your `TYPESAFE_API_KEY` in the CLI:

<Switch>

<Case id="python">

```bash
pip install typesafe-sdk
export TYPESAFE_API_KEY=<your-typesafe-api-key>
```

</Case>

<Case id="typescript">

```bash
npm install @typesafe-ai/sdk
export TYPESAFE_API_KEY=<your-typesafe-api-key>
```

</Case>

</Switch>

<Only id="python">

Alternatively, if you're working in a notebook environment (e.g., Jupyter or Colab), set your `TYPESAFE_API_KEY` in a cell:

```bash
%env TYPESAFE_API_KEY=<your-typesafe-api-key>
```

</Only>

You can also save it with `deepeval`'s CLI, which accepts `--model` and `--cost-per-input-token` too (run <Term py="deepeval unset-typesafe" ts="npx deepeval unset-typesafe"/> to remove it):

<Switch>

<Case id="python">

```bash
deepeval set-typesafe --prompt-api-key --save=dotenv
```

</Case>

<Case id="typescript">

```bash
npx deepeval set-typesafe --prompt-api-key --save=dotenv
```

</Case>

</Switch>

### In Code

To use Jev for `deepeval` metrics, define a `TypeSafeModel` and pass it as the metric's <Term py="system_one_model" ts="systemOneModel"/>. By default, the `model` is set to <DefaultSystemOneModel />.

<Switch>

<Case id="python">

<Tabs items={["Python", "ENV"]}>
<Tab value="Python">

```python
from deepeval.metrics import AnswerRelevancyMetric
from deepeval.models import TypeSafeModel

model = TypeSafeModel(model="jev-latest")
answer_relevancy = AnswerRelevancyMetric(
    system_one_model=model,
    eval_mode="system_one",
)
```

There are **ZERO** mandatory and **THREE** optional parameters when creating a `TypeSafeModel`:

- [Optional] `model`: A string specifying which Jev model to use. Defaults to `TYPESAFE_MODEL_NAME` if not passed; falls back to <DefaultSystemOneModel /> if unset.
- [Optional] `api_key`: A string specifying your TypeSafe AI API key. Defaults to `TYPESAFE_API_KEY` if not passed; raises an error at runtime if unset.
- [Optional] `cost_per_input_token`: A float specifying the cost for each input token for the provided model. Defaults to `TYPESAFE_COST_PER_INPUT_TOKEN`, then to `deepeval`'s pricing for known Jev models. Jev does not charge for output tokens.

Extra `**kwargs` passed to `TypeSafeModel(...)` are forwarded to the underlying `TypeSafeClient`.

</Tab>
<Tab value="ENV">

With `TYPESAFE_API_KEY` set, pass the name of your desired Jev model as the metric's `system_one_model`, or leave it out to use `TYPESAFE_MODEL_NAME` (falling back to <DefaultSystemOneModel />):

```python
from deepeval.metrics import AnswerRelevancyMetric

answer_relevancy = AnswerRelevancyMetric(
    system_one_model="jev-latest",
    eval_mode="system_one",
)
```

To use Jev in every metric without passing `eval_mode`, set the eval mode once with `deepeval set-eval-mode hybrid` or `deepeval set-eval-mode system_one`.

</Tab>
</Tabs>

</Case>

<Case id="typescript">

<Tabs items={["TypeScript", "ENV"]}>
<Tab value="TypeScript">

```typescript
import { AnswerRelevancyMetric } from "deepeval/metrics";
import { TypeSafeModel } from "deepeval/models";

const model = new TypeSafeModel({ model: "jev-latest" });
const answerRelevancy = new AnswerRelevancyMetric({
  systemOneModel: model,
  evalMode: "system_one",
});
```

There are **ZERO** mandatory and **THREE** optional parameters when creating a `TypeSafeModel`:

- [Optional] `model`: A string specifying which Jev model to use. Defaults to `TYPESAFE_MODEL_NAME` if not passed; falls back to <DefaultSystemOneModel /> if unset.
- [Optional] `apiKey`: A string specifying your TypeSafe AI API key. Defaults to `TYPESAFE_API_KEY` if not passed; throws when the model is created if unset.
- [Optional] `costPerInputToken`: A number specifying the cost for each input token for the provided model. Defaults to `TYPESAFE_COST_PER_INPUT_TOKEN`, then to `deepeval`'s pricing for known Jev models. Jev does not charge for output tokens.

Any other option passed to `new TypeSafeModel({...})`, such as `baseURL`, is forwarded to the underlying `TypeSafeClient`.

</Tab>
<Tab value="ENV">

With `TYPESAFE_API_KEY` set, pass the name of your desired Jev model as the metric's `systemOneModel`, or leave it out to use `TYPESAFE_MODEL_NAME` (falling back to <DefaultSystemOneModel />):

```typescript
import { AnswerRelevancyMetric } from "deepeval/metrics";

const answerRelevancy = new AnswerRelevancyMetric({
  systemOneModel: "jev-latest",
  evalMode: "system_one",
});
```

To use Jev in every metric without passing `evalMode`, set the eval mode once with `npx deepeval set-eval-mode hybrid` or `npx deepeval set-eval-mode system_one`.

</Tab>
</Tabs>

</Case>

</Switch>
