`deepeval`'s integration with [Atlas Cloud](https://www.atlascloud.ai/) allows you to use the Atlas Cloud gateway, connecting any model on Atlas Cloud (OpenAI, Anthropic, DeepSeek, Qwen, GLM, Kimi, and more, behind one OpenAI-compatible endpoint) to power all of `deepeval`'s metrics.

### Command Line

To configure your Atlas Cloud model through the CLI, run the following command:

```bash
deepeval set-atlascloud \
    --model "openai/gpt-4.1-mini" \ # Ex: openai/gpt-4.1-mini, deepseek-ai/deepseek-v3.2
    --base-url "https://api.atlascloud.ai/v1" \
    --temperature=0 \
    --prompt-api-key
```

:::info
The CLI command above sets Atlas Cloud as the default provider for all metrics, unless overridden in code. To use a different default model provider, you must first unset Atlas Cloud:

```bash
deepeval unset-atlascloud
```
:::

:::tip[Persisting settings]
You can persist CLI settings with the optional `--save` flag.
See [Flags and Configs -> Persisting CLI settings](/docs/evaluation-flags-and-configs#persisting-cli-settings-with---save).
:::

### In Code

Alternatively, you can define `AtlasCloudModel` directly in code:

<Tabs items={["Python", "ENV"]}>
<Tab value="Python">

```python
from deepeval.metrics import AnswerRelevancyMetric
from deepeval.models import AtlasCloudModel

model = AtlasCloudModel(
    model="openai/gpt-4.1-mini",
    api_key="your-atlascloud-api-key",
    # Optional: override the default Atlas Cloud endpoint
    base_url="https://api.atlascloud.ai/v1",
)

answer_relevancy = AnswerRelevancyMetric(model=model)
```

There are **ZERO** mandatory and **SIX** optional parameters when creating an `AtlasCloudModel`:

- [Optional] `model`: A string specifying the Atlas Cloud model to use. Defaults to `ATLASCLOUD_MODEL_NAME` if set; otherwise falls back to `openai/gpt-4.1-mini`.
- [Optional] `api_key`: A string specifying your Atlas Cloud API key for authentication. Defaults to `ATLASCLOUD_API_KEY` if not passed; raises an error at runtime if unset.
- [Optional] `base_url`: A string specifying the base URL for the Atlas Cloud API endpoint. Defaults to `ATLASCLOUD_BASE_URL` if set; otherwise falls back to `"https://api.atlascloud.ai/v1"`.
- [Optional] `temperature`: A float specifying the model temperature. Defaults to `TEMPERATURE` if not passed; falls back to `0.0` if unset.
- [Optional] `cost_per_input_token`: A float specifying the cost for each input token for the provided model. Defaults to `ATLASCLOUD_COST_PER_INPUT_TOKEN` if not passed; falls back to `None` if unset (cost is then reported as unknown).
- [Optional] `cost_per_output_token`: A float specifying the cost for each output token for the provided model. Defaults to `ATLASCLOUD_COST_PER_OUTPUT_TOKEN` if not passed; falls back to `None` if unset (cost is then reported as unknown).

Any additional `**kwargs` you would like to use for your Atlas Cloud client can be passed directly to `AtlasCloudModel(...)`. These are forwarded to the underlying OpenAI client constructor. We recommend double-checking the parameters supported by your chosen model in the [Atlas Cloud docs](https://docs.atlascloud.ai/).

</Tab>
<Tab value="ENV">

To use any Atlas Cloud model directly in `deepeval`, set `USE_ATLASCLOUD_MODEL=1` in your `env` and simply pass the name of your desired model in your metric initialization:

```python
from deepeval.metrics import AnswerRelevancyMetric

answer_relevancy = AnswerRelevancyMetric(
    model="openai/gpt-4.1-mini",
)
```

You should also set the other necessary vars like `ATLASCLOUD_API_KEY` to be able to use Atlas Cloud models as shown above.
