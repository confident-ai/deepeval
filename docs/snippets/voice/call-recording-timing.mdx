When the test case has a `call_recording_path`, a stereo WAV of the whole call with the caller on the left channel and the agent on the right (the simulator writes one when [`record_call=True`](/docs/conversation-simulator-voice-mode)), the metric reads who was making sound when from each channel's loudness: 20 ms frames, pauses under 0.3 seconds closed, sounds under 0.15 seconds dropped. This does not depend on how the turns were cut, so it is the more reliable source. Without one, or with a mono file, the metric falls back to each turn's `start_time` and audio length. `timing_source` on `score_breakdown` says which was used.
