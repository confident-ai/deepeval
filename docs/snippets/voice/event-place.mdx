Every event also carries `mark`, `timing_source` and `description`. `mark` says what the event's `start_time` and `duration_seconds` cover: `moment` is the spot where the problem happened, `range` is the stretch it lasted, and `whole_reply` is the agent reply it was judged on. `timing_source` is `call_recording` when that place was read from the stereo call recording, or `turn_timestamps` when it comes from each turn's `Audio.start_time`, so it is only as accurate as those timestamps. `description` is one sentence about the problem, such as "Agent took 5.2s to reply". An event with no `start_time` could not be placed on the call's clock.
